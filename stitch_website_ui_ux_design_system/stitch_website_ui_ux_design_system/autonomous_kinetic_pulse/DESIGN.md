## Brand & Style

This design system blends **Dark Cyber precision** with **High-Trust Fintech instrumentation**, tailored specifically for non-technical small and medium business owners navigating automated Meta advertising. The interface evokes stability, high-tech efficiency, and financial security—eliminating the anxiety of erratic ad spend and complex technical configurations.

### Key Attributes
- **Mission-Critical Reliability:** Interfaces avoid playful or whimsical flourishes in favor of calm, deliberate metrics, structured telemetry grids, and crystal-clear transaction states.
- **Cognitive Clarity for Mature Operators:** Given a primary audience of seasoned business owners (around 45 years of age), the visual presentation emphasizes high legibility, generous target sizing, explicit state feedback, and uncompromised contrast against dark backdrops.
- **Automated Intelligence:** Subtle neon accents signal active system intelligence, automated budget optimization, and algorithmic health without creating visual fatigue.

## Colors

The palette is engineered for prolonged data monitoring in high-stakes financial and marketing scenarios, balancing deep slate voids with luminous status indicators.

### Background & Surface Hierarchy
- **Base Canvas (`#0B0F19`):** Pure deep obsidian slate. Serves as the global backdrop.
- **Card / Surface Default (`#111827`):** Elevated structural container surface.
- **Surface Hover / Highlight (`#1F2937`):** Interactive elevation for rows, card headers, and dropdown panels.
- **Border Subtle (`#1E293B`):** Low-contrast architectural grid divider.
- **Border Focus / Active (`#334155`):** Explicit structural outline for focused controls.

### Functional & Signal Accents
- **Primary Cyber Blue (`#38BDF8` / `#2563EB`):** Represents system autonomy, navigation, selected active states, and core actionable buttons.
- **Financial Safe Emerald (`#10B981`):** Signifies profitable ROAS, live active campaigns, successful automated bids, and operational health.
- **Budget Caution Amber (`#F59E0B`):** Highlights learning phase anomalies, impending daily limits, and threshold reviews.
- **Emergency Halt Red (`#EF4444`):** Flags rejected ads, budget spikes, account disconnection, and critical campaign stops.

### Text Contrast
- **High Emphasis (`#F8FAFC`):** Primary headings, currency numbers, and critical metrics.
- **Medium Emphasis (`#94A3B8`):** Explanatory labels, table headers, and status descriptions.
- **Subtle / Disabled (`#475569`):** Inactive placeholders and secondary timestamps.

## Typography

The type hierarchy prioritizes modern Vietnamese diacritical legibility, vertical scanning comfort, and high-contrast numerical metrics. **Plus Jakarta Sans** provides open counters, tall x-height, and refined geometric forms that keep dense financial figures and advertising copy effortlessly readable across both desktop workstations and mobile screens.

### Design Principles
- **Numerical Weighting:** Financial indicators, cost-per-result, and ROAS calculations use `metric-display` with bold weight (`700` or `800`) to enable rapid dashboard scanning.
- **Clarity Over Compaction:** Body text does not drop below 13px; microcopy maintains explicit line spacing (`lineHeight: 18px`) to ensure accessibility for mature users without causing strain.
- **Diacritical Protection:** Line heights accommodate double tone marks in Vietnamese (`ơ`, `ư`, `ê`, `ấ`, `ặ`) without clipping or overlapping adjacent lines.

## Layout & Spacing

A 12-column responsive fluid grid aligns high-density data cards, automated campaign controls, and telemetry charts.

### Form Factor Adaptations
- **Desktop (1280px+):** 12-column layout with `margin-desktop` (32px) and `gutter-desktop` (24px). Sidebar navigation remains anchored at 260px fixed width, reserving the canvas for dynamic ad status tables and real-time ROI charts.
- **Tablet (768px - 1279px):** 8-column layout. Metric cards collapse into 2-by-2 arrangements; contextual charts expand to full container width.
- **Mobile (<768px):** 4-column layout with `margin` (16px) and `gutter` (20px). Action buttons occupy full bottom sheets, while metric tables switch to stacked list views with horizontal badge tags.

### Spacing Principles
- Internal card padding defaults strictly to `space-lg` (24px) on desktop and `space-md` (16px) on mobile to maintain breathable separation between monetary metrics and secondary actions.
- Form field stacks and modal rows preserve `space-md` gaps to prevent accidental taps on critical campaign configuration inputs.

## Elevation & Depth

This system avoids heavy drop shadows, relying instead on **tonal layered surfaces**, **diffused neon glow borders**, and **subtle glass backdrops**.

### Depth Layers
- **Tier 0 (Backdrop):** `#0B0F19`. Complete non-interactive bottom plane.
- **Tier 1 (Base Cards & Modules):** `#111827` overlaid with a 1px structural outline of `#1E293B`.
- **Tier 2 (Floating Popovers & Flyout Drawers):** `#1A2234` surrounded by an ambient soft glow: `0 8px 32px -4px rgba(0, 0, 0, 0.65), 0 0 0 1px rgba(56, 189, 248, 0.12)`.
- **Tier 3 (Urgent Modals & Emergency Overlays):** `#0F172A` with a subtle frosted glass backdrop filter (`backdrop-filter: blur(12px)`) and a high-visibility boundary outline: `0 0 0 1px #334155`.

### Laser-Focus Glows
Interactive inputs and critical actionable buttons emit a controlled primary radiance (`box-shadow: 0 0 20px -3px rgba(56, 189, 248, 0.25)`) when active, emphasizing the system's cybernetic responsiveness without cluttering the screen.

## Shapes

The design system adopts **Roundedness Level 2 (Rounded)**, creating balanced corner architecture that feels modern, precise, and approachable rather than rigidly industrial or excessively toy-like.

- **Standard Elements (0.5rem / 8px):** Input fields, inline filter chips, table rows, and secondary action buttons.
- **Card Containers (`rounded-lg` / 1rem / 16px):** Campaign cards, real-time ROI charts, budget allocation blocks, and modal dialogs.
- **Hero Containers (`rounded-xl` / 1.5rem / 24px):** Setup wizards, multi-step campaign generators, and executive overview panels.
- **Badges & Switches (`rounded-full`):** Status badges and automated master switches retain pill profiles for immediate biological recognition.

## Components

### Buttons
- **Primary Automation CTA:** Solid gradient transition from `#2563EB` to `#38BDF8` with white high-contrast text (`#FFFFFF`), semi-bold weight, 48px height, and a 0.5rem corner radius. On hover, displays an ambient cyber blue glow (`rgba(56, 189, 248, 0.35)`).
- **Emergency Halt / Kill Switch Button:** Deep crimson base (`#EF4444`) with high-contrast text and a prominent stop icon. Sized generously (min-height 48px) to allow instant mobile or desktop access during live budget anomalies.
- **Secondary Ghost Action:** Transparent background, 1px border (`#334155`), text color (`#94A3B8`). On hover, transitions to `#1E293B` background and `#F8FAFC` text.

### Status Badges & Chips
- **Hoạt động (Active / Stable):** Background `rgba(16, 185, 129, 0.12)`, text `#10B981`, border `1px solid rgba(16, 185, 129, 0.3)`. Accompanied by a pulsing green 6px circular indicator.
- **Đang học máy (Learning Phase):** Background `rgba(245, 158, 11, 0.12)`, text `#F59E0B`, border `1px solid rgba(245, 158, 11, 0.3)`.
- **Tạm dừng / Lỗi (Halted / Error):** Background `rgba(239, 68, 68, 0.15)`, text `#EF4444`, border `1px solid rgba(239, 68, 68, 0.35)`.
- Badge text uses `label-md` uppercase styling with `0.04em` letter spacing for rapid recognition.

### Input Fields & Controls
- **Ad Setup Inputs:** Dark fill (`#0B0F19`), height 48px, 1px border (`#1E293B`), text `#F8FAFC`, placeholder `#475569`. Focus state applies a `#38BDF8` border and a 3px soft blue ring glow.
- **Automated Mode Switches:** Oversized toggle switches (52px width, 28px height) with emerald active tracks (`#10B981`) and bright thumbs (`#FFFFFF`) to make automated meta-bidding states unequivocal.

### Financial & Metric Cards
- Constructed with `#111827` surface background, 16px corner radius, and subtle top borders carrying high-tech status accent strips (2px top rim in `#38BDF8` or `#10B981`).
- Card layout strictly places metric titles in `body-sm` (`#94A3B8`), primary values in `metric-display` (`#F8FAFC`), and delta rates (e.g., `+18.4% chi phí đơn hàng`) in small badges anchored directly below the figure.

### Data Tables
- Header cells styled with `#111827` background, `label-md` font, `#94A3B8` uppercase text, and an explicit bottom divider (`#1E293B`).
- Alternating row hovers illuminate to `#1A2234` with smooth 150ms transitions, ensuring 45-year-old business owners do not lose their line position when auditing line-by-line Meta ad sets.
